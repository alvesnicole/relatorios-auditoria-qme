  Justificativa           : O problema pede o conjunto de notas que aparecem em pelo menos duas avaliações. Isso significa que precisamos encontrar a interseção de pares de conjuntos e depois unir esses resultados. 

A) Calcula (A ∩ B) ∪ (A ∩ C) ∪ (B ∩ C). A ∩ B = {5, 7}. A ∩ C = {4, 6}. B ∩ C = {}. Portanto, (A ∩ B) ∪ (A ∩ C) ∪ (B ∩ C) = {5, 7} ∪ {4, 6} ∪ {} = {4, 5, 6, 7}. Esta alternativa está correta.
B) Calcula (A ∪ B) ∩ C. A ∪ B = {4, 5, 6, 7, 8}. (A ∪ B) ∩ C = {4, 6, 8}. Esta alternativa está incorreta.
C) Calcula (A ∩ B) ∪ C. A ∩ B = {5, 7}. (A ∩ B) ∪ C = {5, 7} ∪ {4, 6, 8, 9} = {4, 5, 6, 7, 8, 9}. Esta alternativa está incorreta.
D) Calcula A ∪ B ∪ C. A ∪ B ∪ C = {4, 5, 6, 7, 8, 9}. Esta alternativa está incorreta.
E) Calcula (A ∩ B) ∩ C. A ∩ B = {5, 7}. (A ∩ B) ∩ C = {} (vazio). Esta alternativa está incorreta.

A alternativa A é a única que calcula corretamente o conjunto das notas que aparecem em pelo menos duas avaliações.
