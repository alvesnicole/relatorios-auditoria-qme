3. GABARITO CEGO E DISTRATORES (G18–G19, G21–G31)
----------------------------------------
  Resolução cega          : A
  Justificativa           : O sólido é limitado por $x^2 + y^2 = 4$, que é um cilindro de raio 2, e pelos planos $z=0$ e $z=3$. Em coordenadas cilíndricas, $x = rho$, $y = r	heta$, e $z = z$. A densidade é dada por $ho(x,y,z) = x^2 + y^2$.  Portanto, em coordenadas cilíndricas, $ho(x,y,z) = r^2$. A integral tripla deve integrar sobre o volume do cilindro. O raio do cilindro é 2, então $0 	ext{ } 	ext{le } r 	ext{ } 	ext{le } 2$. O ângulo varia de $0 	ext{ } 	ext{le } 	heta 	ext{ } 	ext{le } 2	ext{π}$. A altura varia de $0 	ext{ } 	ext{le } z 	ext{ } 	ext{le } 3$. A integral tripla é então $∫_0^{2π}∫_0^2∫_0^3 r^2 dz dr dθ$.

Análise das alternativas:

A) $∫_0^{2π}∫_0^2∫_0^3 r^2 dz dr dθ$ - Parece correta, pois segue a ordem correta e os limites corretos.
B) $∫_0^{2π}∫_0^2∫_0^3 r^3 dz dr dθ$ - Incorreta, pois a densidade é $r^2$, não $r^3$.
C) $∫_0^{2π}∫_0^4∫_0^3 r dz dr dθ$ - Incorreta, pois o limite superior de integração em 'r' é 2, não 4.
D) $∫_0^{π}∫_0^2∫_0^3 r^2 dz dr dθ$ - Incorreta, pois o limite inferior de integração em 'θ' é 0, e o superior é $2	ext{π}$, não $	ext{π}$.
E) $∫_0^{2π}∫_0^2∫_0^3 r^2 dr dz dθ$ - Incorreta, pois a ordem de integração está incorreta. A ordem correta é $dz dr dθ$.

Todas as regras foram verificadas e a alternativa A é a única que satisfaz todas as condições.
