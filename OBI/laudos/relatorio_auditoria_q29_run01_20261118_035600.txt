3. GABARITO CEGO E DISTRATORES (G18–G19, G21–G31)
----------------------------------------
  Resolução cega          : E
  Justificativa           : O problema exige determinar qual valor de troco é impossível de ser dado com as cédulas disponíveis: $1, $3, $9, $27, $81. Para cada alternativa, tentaremos construir o troco somando as cédulas de forma a atingir o valor desejado. Se não for possível, a alternativa será a resposta. 

A) $40,00: $81 + $9 + $3 + $1 + $3 + $3 = $40. Possível.
B) $35,00: $27 + $3 + $3 + $1 + $1 = $35. Possível.
C) $31,00: $27 + $3 + $1 = $31. Possível.
D) $13,00: $9 + $3 + $1 = $13. Possível.
E) $4,00: Não é possível formar $4,00 apenas com as cédulas disponíveis. O menor valor é $1, e não há como combinar as cédulas para chegar a $4,00 sem usar $1 mais de uma vez.

Portanto, $4,00 é o único valor que não pode ser dado como troco.
  Confere com o oficial   : Não
  Alternativas:
    [A] Distrator (Plausibilidade: 4/5)
         → Aluno pode não considerar a combinação de todas as cédulas para atingir o valor de troco, focando em uma única cédula.
    [C] Distrator (Plausibilidade: 3/5)
         → Aluno pode não entender a restrição de usar apenas uma de cada valor de cédula, somando valores de forma incorreta.
    [D] Distrator (Plausibilidade: 3/5)
         → Aluno pode se confundir com a necessidade de usar todas as cédulas para formar o troco, não considerando combinações.
    [E] Distrator (Plausibilidade: 2/5)
         → Aluno pode achar que qualquer valor pequeno é possível, sem considerar a combinação das cédulas disponíveis.
  Violações (G21–G24, G27–G31): Nenhuma detectada.
