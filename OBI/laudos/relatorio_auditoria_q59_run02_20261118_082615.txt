----------------------------------------
  Resolução cega          : E
  Justificativa           : O problema envolve encontrar o menor custo de pedágios para um caminhão de 18 toneladas sair de Lagoa e chegar a Queimada, considerando restrições de peso em duas pontes. As estradas são: Lagoa-Matão, Olaria-Porto, Nazaré-Olaria, Olaria-Matão, Matão-Porto, Queimada-Nazaré. O caminhão não pode usar a estrada Olaria-Porto (peso máximo 20 toneladas) nem a estrada Olaria-Matão (peso máximo 15 toneladas). Portanto, o caminhão deve evitar essas estradas. Uma possível rota é Lagoa -> Matão -> Porto -> Queimada -> Nazaré -> Olaria. Essa rota não é possível pois não existe estrada direta de Queimada para Nazaré. A rota mais curta é Lagoa -> Matão -> Porto -> Queimada -> Nazaré -> Olaria -> Matão. Essa rota também não é possível pois o caminhão não pode passar pela ponte de Olaria-Matão. A rota correta é Lagoa -> Matão -> Porto -> Queimada -> Nazaré -> Olaria. O caminhão não pode usar a ponte de Olaria-Matão, então ele deve usar a rota Lagoa -> Matão -> Porto -> Queimada -> Nazaré -> Olaria. O custo total seria 2+2+2+2+2 = 10. A rota Lagoa -> Matão -> Porto -> Queimada -> Nazaré -> Olaria -> Matão não é possível pois o caminhão não pode passar pela ponte de Olaria-Matão. A rota Lagoa -> Matão -> Porto -> Queimada -> Nazaré -> Olaria é a única possível. O custo total é 5 pedágios * R$2,00 = R$10,00.
