3. GABARITO CEGO E DISTRATORES (G18–G19, G21–G31)
----------------------------------------
  Resolução cega          : B
  Justificativa           : O enunciado descreve RAID como uma tecnologia que combina múltiplos discos para melhorar segurança e performance. A questão pede para identificar a alternativa que NÃO representa um tipo de RAID válido. 

A) RAID 1 (Espelhamento): É um tipo de RAID válido, que replica dados em dois ou mais discos.
B) RAID 8 (híbrido): Embora existam variações de RAID que combinam diferentes níveis, RAID 8 não é um nível RAID padrão amplamente reconhecido. É uma opção menos comum e pode ser considerada inválida neste contexto.
C) RAID 5 (Paridade): É um tipo de RAID válido, que utiliza paridade distribuída para garantir a redundância dos dados.
D) RAID 0 (Striping): É um tipo de RAID válido, que divide dados entre múltiplos discos para aumentar a velocidade.

Considerando a falta de reconhecimento generalizado do RAID 8, esta alternativa é a mais provável de ser a resposta correta.
  Confere com o oficial   : Sim
  Alternativas:
    [A] Distrator (Plausibilidade: 3/5)
         → Alunos podem confundir RAID 1 com uma solução de backup, ignorando que é um espelhamento de dados para redundância.
    [C] Distrator (Plausibilidade: 4/5)
         → A confusão surge da familiaridade com o conceito de paridade, mas a aplicação específica em RAID pode ser mal compreendida.
    [D] Distrator (Plausibilidade: 2/5)
         → Alunos podem não ter conhecimento dos diferentes níveis de RAID e confundir 'striping' com outros métodos de organização de dados.
