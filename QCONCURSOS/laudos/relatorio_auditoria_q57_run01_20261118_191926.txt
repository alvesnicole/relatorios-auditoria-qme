3. GABARITO CEGO E DISTRATORES (G18–G19, G21–G31)
----------------------------------------
  Resolução cega          : A
  Justificativa           : O enunciado descreve um cenário de edição de imagens, modelagem 3D e renderização, atividades que exigem alto poder de processamento e cálculos simultâneos. A alternativa que melhor se adequa a essa necessidade é a GPU, pois é projetada para processamento paralelo de dados visuais. A CPU é de propósito geral, a RAM é para armazenamento temporário, o SSD é para armazenamento persistente e o chipset gerencia a comunicação, não realizando o processamento pesado diretamente. 

Análise das alternativas:

A) GPU: Adequada para processamento de imagens e cálculos paralelos.
B) CPU: Propósito geral, não otimizada para tarefas específicas como renderização.
C) RAM: Armazenamento temporário, não realiza processamento.
D) SSD: Armazenamento, não realiza processamento.
E) Chipset: Gerenciamento de comunicação, não realiza processamento.

Considerando a natureza das tarefas, a GPU é a escolha mais apropriada.
  Confere com o oficial   : Sim
  Alternativas:
    [B] Distrator (Plausibilidade: 4/5)
         → Alunos podem confundir a CPU como responsável por todas as tarefas, ignorando a especialização da GPU para processamento de imagem.
    [C] Distrator (Plausibilidade: 3/5)
         → Confundem a RAM como a principal responsável pelo desempenho, sem entender a importância da GPU para cálculos específicos.
    [D] Distrator (Plausibilidade: 3/5)
         → Consideram o armazenamento rápido como solução para o problema, sem entender que o gargalo é o processamento.
    [E] Distrator (Plausibilidade: 2/5)
         → Ignoram a função específica do chipset e o confundem com a principal responsável pelo desempenho.
  Violações (G21–G24, G27–G31):
