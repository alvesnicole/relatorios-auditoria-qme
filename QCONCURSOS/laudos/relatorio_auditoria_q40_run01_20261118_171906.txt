3. GABARITO CEGO E DISTRATORES (G18–G19, G21–G31)
----------------------------------------
  Resolução cega          : E
  Justificativa           : O comando `ifconfig -a` no Linux é usado para exibir informações detalhadas sobre as interfaces de rede. A opção `-a` significa 'all' (todas), e faz com que o comando liste todas as interfaces, incluindo as que estão desativadas ou virtuais. Analisando as alternativas:

A) Permite a definição de um endereço IP para uma interface de rede: Isso é feito com o comando `ifconfig <interface> <ip_address>`, não com `-a`.
B) Permite definir a máscara de uma subrede: Similarmente, a máscara é definida com `ifconfig <interface> <ip_address> netmask <subnet_mask>`.
C) Ativa uma interface de rede: O comando para ativar é `ifconfig <interface> up`.
D) Desativa uma interface de rede: O comando para desativar é `ifconfig <interface> down`.
E) Exibe informações sobre todas as interfaces de rede: Esta alternativa descreve precisamente a função do `ifconfig -a`.

Portanto, a alternativa E é a única que corresponde à descrição do comando `ifconfig -a`.
