----------------------------------------
  Resolução cega          : C
  Justificativa           : Análise do problema: O enunciado descreve o uso de SSD, RAM e cache em um computador. O objetivo é identificar a afirmação que descreve corretamente esses componentes. 

Análise das alternativas:

A) Incorreta: A memória cache geralmente tem menor capacidade que a RAM. A afirmação de que a cache mantém dados após o desligamento é falsa, pois é volátil.
B) Incorreta: A RAM é usada para dados em uso, não apenas para arquivos permanentes. O SSD armazena o sistema operacional e programas, não apenas executa instruções.
C) Correta: Esta alternativa descreve corretamente a função de cada componente. O SSD armazena dados persistentemente, a RAM armazena dados em uso e a cache acelera o acesso aos dados frequentemente utilizados.
D) Incorreta: A RAM e a cache são tipos de memória, não armazenamento permanente. A RAM é volátil, enquanto o SSD é um dispositivo de armazenamento persistente.
  Confere com o oficial   : Sim
  Alternativas:
    [A] Distrator (Plausibilidade: 4/5)
         → Confusão entre memória cache e RAM, acreditando que a cache tem maior capacidade e persiste após o desligamento.
    [B] Distrator (Plausibilidade: 3/5)
         → Interpretação errônea do papel da RAM como armazenamento permanente e do SSD como executor de instruções.
    [D] Distrator (Plausibilidade: 2/5)
         → Ignora a diferença fundamental entre armazenamento volátil (RAM, cache) e armazenamento não volátil (SSD), confundindo-os como tipos de armazenamento permanente.
